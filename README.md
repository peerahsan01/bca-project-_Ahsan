Student Grade Management System

1. Project Introduction

The Student Grade Management System is a C programming project designed to store student names and marks, calculate average marks, and assign grades.

This project demonstrates the use of arrays and structures in C programming.

2. Project Objectives

* To store student names and marks.
* To understand arrays and structures.
* To calculate the average marks of students.
* To assign grades based on student performance.
* To display student records clearly.

3. Technologies Used

* Programming Language: C
* Concepts Used: Arrays, Structures, Loops and Conditional Statements.
* Platform: GitHub

4. Features

* Stores multiple student records.
* Accepts student names and marks.
* Calculates average marks.
* Assigns grades according to performance.
* Displays student details and results.

5. How to Run the Program

1. Download the student_grade.c file.
2. Open it in a C compiler.
3. Compile the program.
4. Run the program.
5. Enter student names and marks to view the results.

6. Project Files

* student_grade.c – Main C source code.
* Project_Report.pdf – Detailed project report.
* screenshots/ – Program and output screenshots.

7. Expected Output

The program displays student names, marks, average marks, and grades.
